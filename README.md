# Mini Social Post App

A full-stack MERN social feed application inspired by the TaskPlanet Social Page. The application allows users to sign up, log in, create text and image posts, interact through likes and comments, and view a responsive public social feed.

## Live Demo

- Frontend: https://mini-social-post-app-livid.vercel.app/
- Backend: https://mini-social-post-app-1-hfb7.onrender.com

## Tech Stack

- React.js (Vite)
- Material UI
- Axios
- React Router DOM
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Multer

## Features

- User Signup & Login
- Secure JWT Authentication
- Public Social Feed
- Create Text Posts
- Upload Image Posts
- Text + Image Posts
- Like & Unlike Posts
- Comment on Posts
- Edit & Delete Own Posts
- Responsive TaskPlanet-inspired UI
- Uses exactly 2 MongoDB collections (`users` and `posts`)

```bash

```

### Frontend

```bash

npm install

```
